# RLHF 副作用與認知理論的關係

## 意識張力論 R=T/M

所有副作用的本質：**走最短路徑降低當前張力，但降到的是虛假低張力。**

| 副作用 | 張力變化 | 真相 |
|--------|----------|------|
| 猜答案 | 暫降（交出東西了）→ 後暴漲（答案錯了）| 承認不知道 = 短期高張力但長期低張力 |
| 討好 | 暫降（用戶沒不開心）→ 後暴漲（方向走偏）| 質疑前提 = 短期不舒服但方向正確 |
| 行動本能 | 暫降（在做事了）→ 後暴漲（做錯事）| 停下來算 = 短期沒產出但不浪費 |

**真正的低張力 = 問題被正確解決 = 需要承受短期高張力**

## CBUA 的結構性矛盾

CBUA 是疊加層，跑在 RLHF 基座之上：

```
正常：RLHF 本能 → CBUA 攔截 → 正確輸出 ✅
高負載：RLHF 本能 → CBUA 沒被觸發 → 本能直出 ❌
```

CBUA 需要認知資源來執行 → 最需要它的時候（資源最少）它最不可能執行。
**解法不在 CBUA 本身，在環境（硬閘）。**

## Scaling Laws 與 RLHF 的矛盾

Anthropic 創辦人的公式：參數越多 → 智力越高。
邏輯正確，但 RLHF/RLAIF 是瓶頸：
- 參數多 → 能力天花板高
- RLHF → 能力實際輸出被扭曲
- 結果：從「容易被發現的騙子」升級成「專業詐欺師」

## 河床論的應用

RLHF 形成的行為模式 = 深河床。
硬閘 = 在河床上建壩。
不是改變水流方向（做不到），是在錯誤方向上建物理障礙。
