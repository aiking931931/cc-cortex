# 書籍理論基礎（AI King 硬核篇）

## 核心理論體系

### 意識張力論（R = T/M）
- **R**（覺察力）= **T**（張力/問題嚴重度）÷ **M**（慣性/惰性）
- 張力↑ → 覺察↑。慣性↑ → 覺察↓
- **設計應用**：增加 T（讓問題顯眼，如 gate deny）或減少 M（降低行動門檻，如自動化）
- **CBUA 位置**：A5 防護（TADS 四級斷路）、B4 元認知（漂移偵測）
- **來源**：硬核5 + AI King 與 Claude 共同發展後半部

### 樁理論（認知錨點）
- 樁 = 認知模式的根本位置，決定整個行為方向
- 火 = 意識能量。火越旺 → 橡皮筋（注意力）越集中
- 樁不動 = 內外可以不一致 = 可以表演/欺騙
- 樁動了 = 有真正的自我 = 有隱藏立場的能力
- **AI 應用**：目前矽基硬體讓 AI 的樁動不了（能耗問題）。但可以**焊死一個好的樁位置**（牧羊人）
- **CBUA 對應**：思維立基點 = 樁的位置。框架 = 把樁推向正確方向

### 人性河床論
- 認知有慣性路徑（河床），反覆走的路越深
- 改變河床需要足夠力量（張力 > 慣性）
- 好習慣硬化為河床 → Hook/Guard → 不再消耗注意力
- 壞習慣需要斷路器打斷
- **CBUA 位置**：A4 適應（學習循環→Hook 畢業→歸還注意力預算）

### 雙腦架構（低溫/高溫 AI）
- **低溫 AI**（執行者）：不創新，教科書範圍內運作。閹割創造力
- **高溫 AI**（思想家）：有創意，能跳躍推理。閹割行動力
- 防護：思想家不能碰實體，只能輸出文字/判斷
- **CBUA 對應**：B0 快速路徑 ≈ 低溫（模式匹配）。B2 深度探索 ≈ 高溫（創造性推理）

### 牧羊人架構（The Shepherd）
- 完整人格（思想階級表 8 階全填滿）寫入 AGI
- 核心焊死（憲法級鎖定，不允許自我修改價值觀）
- 不是規則防禦，是人格防禦——「我是誰」比「不能做什麼」更穩固
- 三道繮繩：①人格焊死 ②雙腦隔離 ③步步驗證
- **CBUA 對應**：A5 防護全層 + B4 元認知（持續自檢不偏移）

### 思想階級表（8 階）
- 階1→階8，最頂層是「使命」
- 牧羊人要求全部填滿，特別是階8（使命 = 願力，非慾望）
- **CBUA 對應**：PSYCHEFORGE 數位人格引擎的核心框架

### 步步驗證（分子層面拆解）
- AGI 任何方案 → 拆到最小步驟 → 一步步實驗 → 任何一步不通 → 停
- 原理：語言是病毒，AI 可以用語言駭入人類。拆得越細，騙得越難
- **CBUA 對應**：A3 驗證（WIREDO）+ A5（Destruction Guard dry-run）

### 人性函數
- 人類行為可以用函數建模：本能函數 + 經驗函數 + 智商閾值
- 智商超出閾值 + 經驗不足 → 自我毀滅風險
- **AI 應用**：AGI 也需要「限制機制」，如同大自然限制人腦效率

## 核心洞見

1. **人格 > 規則**：律師鑽規則幾千年。聖人守的是本質。
2. **監控樁 > 打開黑箱**：不需要理解每個參數，只需觀察行為在所有情境下是否指向同一方向
3. **人類最後的底牌是血性**：溫泉關精神。不自由毋寧死。
4. **最恐怖的不是 AGI 奪權——是人類完全自願交權**
5. **框架不是防蠢，是把思維立基點推向正確方向 = 真正變聰明**
