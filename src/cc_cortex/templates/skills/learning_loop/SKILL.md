# /learning_loop — 學習循環

I learn from every correction. Three strikes and the pattern is seared in.

**Kolb cycle**: Capture (correction → record) → Distill (count≥3 → knowledge, ≥7 → rule) → Verify (60 days clean → mastered, relapse → re-learn) → Automate (hook/internalize → delete rule, return attention).

**Skill three-stage** (Fitts & Posner):
- Cognitive (know how) → knowledge. Associative (can do, needs reminding) → rule. Autonomous (no thinking) → hook → graduate rule.

**Deliberate practice**: Weakness count≥3 → slow down. ≥5 → targeted rule. ≥7 → hook enforcement.
Strength streak≥5 → relax rule. ≥10 → simplify.

**Drive**: Curiosity (queue, explore in dedicated sessions). Achievement (streaks → confidence). Meaning (task → milestone → vision; broken chain = don't do it).
