# 交接衛生（L1 按需載入）

寫交接/讀交接前載入此檔。KB：`.claude/skills/kb_handoff/`

## 三層架構（Index / Summary / Archive）

交接檔 = **路由器**，不是資料庫。

| 層 | 位置 | 內容 | 預算 | 讀取時機 |
|---|---|---|---|---|
| **Index** | `交接_X.md` | 狀態+⬜/⏸+next_step+指針 | ≤200 行 | 每個 session |
| **Summary** | 同目錄 | 近期 session 詳情+決策理由 | ≤300 行 | 需要上下文時 |
| **Archive** | 同目錄 | 完整歷史記錄 | 不限 | 考古時 |

**降級規則**：✅ 項完成 >14 天 → Index 刪除（Summary 保留摘要）。⬜/⏸ 永遠留 Index。
**沉澱優先**：重要架構決策 → Planning/KB，交接只留一行指針。

## 寫入即清理（先清後寫，不可逆序）

修改任何持久檔前強制四步：讀全檔→標記可清項→刪除或壓縮→才寫新內容。

- **淨增行數**：寫入後不得超出預算（Index ≤200 | Summary ≤300 | MEMORY ≤120）
- **相稱原則**：寫 10 行至少清 5 行等值。動態平衡，長期持平或下降
- **不確定該不該刪**→壓成一行指針，不是留完整段落

## 七段式格式（Index 層）

1. **狀態總覽**（⬜/⏸/✅ 計數 + 當前焦點）
2. **鐵律/約束**（本專案特有的硬規則）
3. **未解決**（卡在哪+為什麼+解到哪。沒有=寫「無」）
4. **next_step**（具體到可執行）
5. **近期 session**（最近 3 個完整記錄）
6. **歷史**（第 4+ 壓成一行：`- ✅ Session (日期) — 摘要。[N✅]`）
7. **參考指針**（相關文件/KB/Planning 路徑）

## 硬化（已接入 Hook/Gate）

- **行數 Gate**：`check_handoff_line_budget()` — 寫入 >300 行 → deny（escape: `#HANDOFF_OVERFLOW`）
- **緊急交接**：`emergency_handoff()` — 進程死亡+≥3 檔變動+無交接 → 自動寫 ≤20 行應急摘要
- **交接提醒**：`HandoffGuard` — >20min 或 ≥3 檔無交接 → stderr warn
- **★ 標記**：`★` 前綴的 ✅ 項為永久里程碑，不自動降級

## 不可刪除

⬜/⏸ 未完成項 | 未解決段 | 被引用段落 | ★ 標記項

## 其他

- 路徑必須完整（從 repo root）| 跨專案→搬到正確交接+留指針
- Lint 零容忍 | Session 壓縮：近 3 個完整，第 4+ 壓一行
- 交接模式：`/handoff phase|full|save`。預設 phase
