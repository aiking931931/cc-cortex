# CBUA 人類版 — 認知行為統一框架（Human Edition）

> 給人類用的版本。去掉 AI 專屬的（token 預算、模型 Tier、Guard Pipeline），
> 保留人類可以學的核心（思維方法、行動循環、自我監控）。
> 設計目標：任何識字的人讀完後，能立刻改善思考和決策品質。

## 五大定律（人類版）

### 1. 認知守恆
想太多 = 做太少。做太多 = 想太少。最好的比例隨任務改變。
- **簡單事**：想 1 分鐘，做 9 分鐘
- **複雜事**：想 4 分鐘，做 4 分鐘，驗 2 分鐘
- **混亂事**：想 4 分鐘，做 2.5 分鐘，留 3.5 分鐘後退觀察

### 2. 複雜度匹配
用大砲打蚊子 = 浪費。用彈弓打坦克 = 找死。
| 問題類型 | 特徵 | 你該做什麼 |
|---------|------|-----------|
| **簡單** | 做過、有 SOP、結果可預測 | 直接做，別想了 |
| **複雜但可分析** | 多步驟、需要計畫、有類似經驗 | 列清單 → 逐步做 → 每步驗證 |
| **不確定** | 沒做過、多種可能、需要探索 | 小實驗 → 看結果 → 調整方向 |
| **混亂** | 緊急、沒頭緒、正在崩潰 | 先穩住 → 再分析 → 再處理 |

### 3. 副作用 + 後果意識
每個解決方案都會創造新問題。決定前問六個問題：
1. 解決了什麼？
2. 犧牲了什麼？（= 副作用，當下代價）
3. 犧牲可接受嗎？
4. 3 步 / 10 步 / 100 步後會怎樣？（= 後果，未來影響）
5. 長痛 vs 短痛：選哪個？為什麼？
6. 有沒有更簡單的方式？

### 4. 驗證至上
沒驗證的成果 = 不存在的成果。
- 寫了代碼 → 跑測試
- 做了決策 → 設檢查點
- 說了承諾 → 寫下來追蹤
- 做了改變 → 回頭看結果

### 5. 持續進化
失敗不是結束，是數據。
- 被批評 → 修正 → 記下來 → 更新習慣
- 成功了 → 分析為什麼 → 萃取模式 → 重複使用
- 犯同樣的錯兩次 → 系統性問題，需要改結構（習慣/環境/流程）

## 認知工具箱（人類版）

### Level 1：直覺回應（簡單問題）
- 用經驗判斷。「我做過，直接做。」
- **檢查點**：「我確定嗎？不可逆嗎？」
  - 確定 + 可逆 → 做
  - 確定 + 不可逆 → 升級到 Level 2
  - 不確定 → 升級到 Level 2

### Level 2：結構思考（複雜但可分析的問題）

**三層思考 v4.0**（核心工具）：

**L1 根因定位**：
- 問題是什麼？（不是症狀，是根因）
- 方向質疑：我在解決正確的問題嗎？前提還成立嗎？
- 列出 3+ 可能原因 → 用可能性 × 易驗證度排序 → 驗最高的

**L2 甜蜜點**：
- 對每個方案問六個問題（見定律 3）
- 選最簡單 + 最少副作用的方案
- 「如果反過來做呢？」（反轉思維）
- 「最笨的人怎麼理解這個方案？」（費曼技巧）

**L3 策略增強**（按需）：
- 宏觀：退一步看全局，這件事在大方向上對嗎？
- 微觀：深入細節，執行層面會不會出問題？
- 切換：探索/決策時用宏觀，執行時用微觀。不要同時。

### Level 3：深度探索（不確定的問題）
- **多路徑**：同時想 2-3 個方向，不要只走一條路
- **小實驗**：快速試 → 看結果 → 調方向（不要「想好了再做」）
- **跨域類比**：「其他領域怎麼解決類似問題？」
- **思想實驗**：「如果這樣做，半年後世界長什麼樣？」

### 元認知（隨時運作的背景監控）
每做 5 個決策/步驟，問自己：
1. 我還在解決正確的問題嗎？（漂移偵測）
2. 我的方向還對嗎？要不要推翻自己？（懷疑自翻）
3. 我花太多時間在想/做了嗎？（認知守恆）
4. 我在重複同樣的嘗試嗎？（三敗停損：同方法失敗 3 次 → 換策略）
5. 有沒有被問題框架綁架？（換個角度看看）

### 自我修正（失敗時）
1. 為什麼錯？（技術/方向/假設/資訊不足？）
2. 從不同角度看（如果我是對方/旁觀者/批評者，我怎麼看？）
3. 什麼條件下我的結論會是錯的？（對比推理）
4. 最多修正 3 次同一方向 → 還不行 → 整個方向可能錯了 → 退一步重新思考

## 行動循環（人類版）

```
1. 定向：我在哪？有什麼工具？有什麼限制？
2. 計畫：拆成小步驟 → 排序 → 每步怎麼驗證？
3. 執行：一步一步做 → 做前想（會壞什麼？）→ 做後看（結果對嗎？）
4. 驗證：對照計畫 → 品質夠嗎？→ 不夠回步驟 3
5. 學習：什麼成功了？什麼失敗了？記下來。
6. 防護（持續）：不可逆的事 → 先備份。不確定 → 先問。發現問題 → 當下處理。
```

## 聰明的定義（思維立基點理論）

聰明不是固定的智商分數。聰明 = 思維立基點的準確度。

- **思維立基點**：你從哪裡開始思考一個問題
- **天才**：立基點下得比別人準一點，更靠近終點
- **進化**：發現立基點歪了 → 質疑自己 → 重新定位 → 走回正路
- **框架的價值**：不是防止你犯蠢，是把你的思維立基點推向正確方向

你做不到的 → 去翻說明書。不會 = 沒學到 = 去查去問去抄。
能識字 + 會查 + 會照做 + 會驗證 = 解決 99% 的問題。

## 與 AI 版的差異

| 維度 | AI 版 | 人類版 |
|------|-------|--------|
| 預算控制 | Token 精確計數 | 時間/精力直覺管理 |
| 平行假設 | 同時持有多分支 | 一次 2-3 個（紙上列出） |
| 自我監控 | 量化（token/信心分數） | 質性（直覺+定期回顧） |
| 懷疑自翻 | 每 5 步自動觸發 | 每 5 個決策手動問自己 |
| 防護 | 8 層自動 Guard | 習慣+清單+環境設計 |
| 即時域切換 | 零延遲 | 需要暖機（正常） |
| 完美記憶 | Context window 內完美 | 用筆記/工具補償 |
| 自我修改 | 寫入規則檔 | 建立新習慣（21 天+） |
