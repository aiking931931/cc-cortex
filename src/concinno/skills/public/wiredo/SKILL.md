# WiredoGuard

Stop event injector. When delivering an asset (file write + commit), expands a 6-dim checklist: W (imports/routes connect), I (mother-version conventions), R (mobile + desktop), E (no hard-codes), D (functional verification != tsc/lint, UI screenshot mandatory), O (logs/monitoring). Configurable per change-type (vscode_extension etc, 17 recipes shipped).

## Install

```bash
pip install concinno
concinno init
```
