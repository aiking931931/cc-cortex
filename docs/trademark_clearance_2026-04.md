- **USPTO Class 9/42 registration**: not found in public searches. Requires paid USPTO clearance.

  services) — uncertain, requires paid search. Class 9/42 clearance against Concinno GmbH is

### Cerno

- Justia hit: **VIX** trademark of **Cerno, LLC** — serial 97531246, filed 2022-08-02, registered

  states "Cerno Bioscience is a registered trademark" and lists multiple product marks
  (MassWorks, MassWorks Rx, MassWorks GC/ID, TrueCal, TrueFit, DirectRead, AutoCal, CLIPS, sCLIPS).

  was not directly confirmed in the public mirrors I could crawl; the company's own trademark-symbol

- Latin: *cerno* = "I see / perceive / judge / sift" — distinctive; excellent semantic fit for a

   *ordino* / *compono*.

## Limitations & Honest Caveats

1. **EU / WIPO databases were not crawlable today** — TMview, eSearch Plus, and WIPO Brand DB
   all gate results behind JavaScript + CAPTCHA. Each name flagged "requires paid search" above
   needs commercial-clearance follow-up.
2. **Public USPTO mirrors (Justia, uspto.report) index only registered marks and a subset of
   applications.** Pending applications filed within the last ~90 days may not appear. Paid USPTO
   search via TSDR / attorneys is authoritative.
3. **Common-law rights are not searchable in any TM database** — the Redigo common-law exposure
   (Redigo Carbon, Redigo Digital, Go library) is derived from company-registry + GitHub
   presence, not TM databases.
4. **I am not a lawyer.** This is fact-gathering only. Before any filing, consult a registered
   trademark attorney in each target jurisdiction.
5. **Red team 2's flagged risks (EUIPO Cerno medical devices + Perpetuo Musikverlag) could not
   be resolved today** — those EU leads remain open and must be verified by paid search before
   clearing Cerno / Perpetuo.
